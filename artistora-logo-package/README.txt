NOTES
- The source logo image was 480x293px, so very large print use (e.g. banners
  wider than ~1600px, billboards, signage) will show some softness on close
  inspection. For crisp scaling at any size (business cards to billboards),
  the logo should ideally be rebuilt as a true vector (SVG/AI/EPS) — happy to
  do that next if you want it.
- Always keep clear space around the logo roughly equal to the height of the
  lotus icon, and avoid stretching — scale width/height together.
